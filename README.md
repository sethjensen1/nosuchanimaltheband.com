# nosuchanimaltheband.com

The website for the band No Such Animal. Built with Hugo and Tailwind CSS.

Dependencies:

* hugo
* node
* pnpm

To install node & pnpm:

* https://nodejs.org/en/download
* https://pnpm.io/installation

To install pnpm dependencies:

```
pnpm install
```

The theme is a git submodule. To get it, run:

```
git submodule init
git submodule update
```

As of right now, I'm running Hugo and Tailwind separately — Hugo just notices changes to the output.css file generated by Tailwind using the Tailwind CLI. For development:

```
pnpm tailwindcss -i themes/no-such-theme/assets/css/input.css -o themes/no-such-theme/assets/css/output.css --watch
```

Then when running

```
hugo serve
```

in another shell, everything works pretty well for the moment.

For production, run:

```
bin/build
```
